# SIGNAL FLOW Show Time

舞台・ライブ・イベント・配信・プレゼンテーションなどの現場で使える、シンプルなショータイマーです。

## 主な機能

- 大きく見やすい公演時間表示
- START／PAUSE／RESUME
- 誤操作を防ぐ長押しRESET
- 公演タイトル編集
- 現在時刻表示
- 日本語／English切替
- 常に最前面に表示
- Spaceキーによる操作
- 設定の自動保存
- 使用中のスリープ防止

## 対応状況

初回正式版はmacOSを中心に提供予定です。Windows、iPad、iPhoneなどは順次検証・展開予定です。
