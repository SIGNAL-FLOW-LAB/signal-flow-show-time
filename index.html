Show Time Support

Show Timeは、ライブ・イベント・舞台・配信など、 時間管理が重要な現場のために設計されたシンプルなタイム表示アプリです。

Show Time is a simple time display and stopwatch app designed for live events, stage productions, rehearsals, presentations, and other time-sensitive production environments.

主な機能 / Main Features

  • 現在時刻の表示 / Current time display
  • 公演・作業時間の計測 / Elapsed show or work time
  • START / PAUSE / RESUME / RESET
  • 表示コメントの編集 / Editable display comments
  • 12時間・24時間表示 / 12-hour and 24-hour formats
  • 秒表示のON / OFF / Optional seconds display
  • 縦画面・横画面対応 / Portrait and landscape support

よくある質問 / FAQ

Q. アカウント登録は必要ですか？

いいえ。Show Timeはログインやアカウント登録なしで使用できます。

No. Show Time does not require login or account registration.

Q. インターネット接続は必要ですか？

基本機能の使用にインターネット接続は必要ありません。

An internet connection is not required for the core functions of the app.

Q. コメントは保存されますか？

表示コメントや表示設定は端末内に保存されます。

Display comments and settings are stored locally on the device.

プライバシー / Privacy

Show Timeは、個人情報やユーザーデータを外部サーバーへ送信・収集しません。

Show Time does not collect or transmit personal information or user data to external servers.

アプリ内で保存される設定やコメントは、端末内でのみ使用されます。

Settings and comments stored by the app are used locally on the device only.
